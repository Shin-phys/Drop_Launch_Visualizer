撮影のポイント
  • スマホは横向きに固定し、撮り終わるまで触らない（ズーム・向き・位置を変えない）
  • 斜方投射と自由落下を続けて1本の動画に撮る（条件がそろい、②でそのまま比べられます）
  • カメラは遠くに置いてズームして撮る
  • 240fps のスロー撮影を推奨（最低でも 120fps）。そのぶん暗くなるので明るい場所で
  • 落とす位置と投げる位置はカメラから同じ距離に（床にテープで印を）
  • 背景に机の縁やものさしなど、動かない目印を入れる
もっと見る

・なぜ遠くからズームか：近くから広角で撮ると、手前を通るときと奥を通るときで見かけの大きさと速さが変わります。遠くからズームすると、その差が小さくなって「まっすぐ横から見た運動」に近づきます。三脚は必須です。

・なぜ 240fps か：ズームで大きく写すぶん、画面の中での動きは速くなります。コマ数が多いほど1コマあたりの移動が小さくなり、位置が読み取りやすくなります。露光も自動的に短くなるのでブレも減ります。高さ 1 m の落下は 0.45 秒しかないので、30fps だと落下全体が14コマしか写りません。

・iPhone のスロー動画は書き出しに注意：共有・書き出しをすると「30fps のゆっくり動画」に変換されることがあります。その場合はこのアプリの fps を 30 にしてください。表示される秒数は実時間とずれますが、左右で条件が同じなので比較の結論は変わりません。

・「超スローモーション」は避ける：一部の機種にある、コマを補間して作るモードです。実際には撮影されていないコマが混ざるので、物理の観察には使えません。素直な 120／240fps のスローを選んでください。

・斜めに投げる：真上に投げると水平成分が見えません。30〜60度くらいの角度で、画面を横切るように飛ばしてください。

・手をはなれた後だけを観察します。手で押している間は力がはたらいているので、法則が違います。

・最高点は目で1コマを選ばない：最高点の近くではボールがほとんど動かず、どのコマも同じに見えます。fps を上げても目視の精度は上がりません。「鉛直：時間反転」のミラー再生で上りと下りを重ね、ぴったり合う位置を探すほうが正確です。

・ものさしを一緒に写す：鉛直に立てたものさしを画面内に入れておくと、落下距離を実際の長さで読み取れます。

なぜ Δt で測るのか
「1コマ」は端末によって 1/30 秒だったり 1/240 秒だったりします。そこで観察の単位には Δt ＝ 何コマ分という時間を使い、コマ数と秒の両方を表示しています。 等速かどうかの判定は fps に関係しません。fps が効くのは「Δt が何秒か」を数値で言うときだけです。

Δt ごとに、線を1本ずつ通りますか。

5. 鉛直も見る（横線）

—

オレンジの線を最高点の高さに、その次の線をΔt あとの高さに合わせます。 その先の線はドラッグできません。「等加速度ならここ」という予測だからです。

右の数字は線の位置（最高点からの落下距離）で 0, 1, 4, 9, 16, 25。 そのすぐ左の目盛りは1単位ずつ刻んであり、長い刻みが5つおきです。 上から数えれば位置が、線と線のあいだを数えれば 1, 3, 5, 7, 9 が出ます。

位置は 1, 4, 9, 16／あいだは 1, 3, 5, 7
最高点からの落下距離は、Δt を1つの単位として 1, 4, 9, 16 …（＝ k²）に比例します。これが線の位置です。
そこから となりあう線のあいだの距離を引き算すると 4−1＝3、9−4＝5、16−9＝7 となって、1, 3, 5, 7 … という奇数が出てきます。 （k² − (k−1)² ＝ 2k−1 なので、必ず奇数になります。）
間隔がどんどん広がることは目で見てわかりますが、その広がり方が数えられる整数になっているところが大事です。 水平方向が 1, 1, 1, 1 … の等間隔なのと見くらべてください。

最高点を t = 0 として、下り（+t）と上りの逆再生（−t）を同時に流します。 ふたつは同じに見えますか。
